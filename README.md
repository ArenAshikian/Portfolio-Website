# Aren Ashikian — Portfolio

Production portfolio for **ArenAshikian.com**, built with Vite, React, and handwritten CSS and deployed through GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

Pushes to `main` trigger `.github/workflows/deploy.yml`. GitHub Pages should use **GitHub Actions** as its deployment source. The custom-domain file is `public/CNAME`.
